# Max hand size 6, opening hand 5 (2026-09-14). Game.java copies the starting
# hand (hand=5 in _format.txt) into maxHandSize, so without this line a 5-card
# opening hand also meant discarding to 5 at every end step. EffectZone$
# Command because the avatar never leaves the command zone (Birds of Paradise
# Avatar is the pattern). The opening hand is still the relay's hand=5.
S:Mode$ Continuous | EffectZone$ Command | Affected$ You | SetMaxHandSize$ 6 | Description$ Your maximum hand size is six.
# The upkeep land lives on a SECOND, per-seat card that ForgeServer builds in
# memory (LightningFormat.buildManaCard), because its colour sequence is a
# shuffled bag of the seat's chosen colours and cannot be a fixed script. This
# card carries only the rule that is the same for everyone: wounds become mana.
# LifeLost, not DamageDoneOnce (2026-09-13): damage to a player IS loss of life
# in Forge (Player.addDamage -> loseLife(.., damage=true, ..)), so one trigger
# counts combat, burn, Sheoldred-style "loses life" and paid life alike, with
# no double count. A table of draw punishers took a player from 15 to 7 with
# no crystal to show for it under the old damage-only wording.
T:Mode$ LifeLost | ValidPlayer$ You | TriggerZones$ Command | Execute$ TrigWound | TriggerDescription$ Whenever you lose life, put that many wound counters on this. Then, for each three wound counters on it, remove them and create a Command Crystal. (It's a land with "{T}: Add one mana of any color in your commander's color identity.")
SVar:TrigCrystal:DB$ Token | TokenScript$ command_crystal | TokenOwner$ You
SVar:TrigWound:DB$ PutCounter | Defined$ Self | CounterType$ WOUND | CounterNum$ X | SubAbility$ DBConvert
# Repeat runs its body once BEFORE testing RepeatCheckSVar (do-while), so the
# body itself is gated on GE3 twice: the crystal first, then the removal, both
# read the same pre-removal count.
SVar:DBConvert:DB$ Repeat | RepeatSubAbility$ DBWoundCrystal | RepeatCheckSVar$ Wounds | RepeatSVarCompare$ GE3 | MaxRepeat$ 10
SVar:DBWoundCrystal:DB$ Token | TokenScript$ command_crystal | TokenOwner$ You | ConditionCheckSVar$ Wounds | ConditionSVarCompare$ GE3 | SubAbility$ DBRemoveWounds
SVar:DBRemoveWounds:DB$ RemoveCounter | Defined$ Self | CounterType$ WOUND | CounterNum$ 3 | ConditionCheckSVar$ Wounds | ConditionSVarCompare$ GE3
SVar:Wounds:Count$CardCounters.WOUND
SVar:X:TriggerCount$LifeAmount
# No deck-out (2026-09-11). A 19-card library with clue and cantrip effects
# in the pool ran dry on turn 11 while its owner sat at 37 life against
# opponents at 2 and 4. Drawing from an empty library is nothing here (the
# Mine, Mine, Mine! replacement); you are out when nothing is left to fight
# with instead: library, hand and creatures/planeswalkers all empty. The
# command zone is deliberately NOT counted -- a commander is always
# recastable and the upkeep lands never stop, so counting it would turn this
# into a stalemate rule.
R:Event$ GameLoss | ActiveZones$ Command | ValidPlayer$ You | ValidLoseReason$ Milled | Layer$ CantHappen | Description$ You don't lose the game for drawing from an empty library.
# A state trigger (Mode$ Always) is re-evaluated on EVERY state-based-action
# pass, twice per pass, for every seat. The first version's single SVar
# (Count$ValidLibrary,Hand Card.YouOwn/Plus.Board) ran two isValid scans --
# every player's library and hand, then the whole battlefield -- each time,
# and on a 4-seat board that was ~half of a 58 s turn (2026-09-15, prod
# turn 24). Now the cheap part gates the expensive part: CheckSVar is two
# zone sizes (no per-card scan) and CheckSecondSVar, the battlefield scan,
# only runs once hand and library are already empty. Same rule, same
# state-trigger semantics (the no-outs test loses on turn 1 from a scenario
# board with no zone change), a few list-size reads per pass instead.
T:Mode$ Always | TriggerZones$ Command | CheckSVar$ HandLib | SVarCompare$ EQ0 | CheckSecondSVar$ Board | SecondSVarCompare$ EQ0 | Execute$ TrigOut | TriggerDescription$ When your library and hand are empty and you control no creatures or planeswalkers, you lose the game.
SVar:TrigOut:DB$ LosesGame | Defined$ You
SVar:HandLib:Count$CardsInYourHand/Plus.Lib
SVar:Lib:Count$CardsInYourLibrary
